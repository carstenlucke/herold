# 12 Glossary

Terms used throughout this architecture documentation. **Domain terms are canonical in the spec glossary [`E2`](../spec/E2-glossar.md)** (Dispatcher, Message Type, Note Status, Operator, Out-of-band, Pipeline, Prompt Injection, Recovery, Shared Hosting, Synchronous Processing, TOTP, Voice Note, …) and are not repeated here. This chapter defines the *architecture- and implementation-level* vocabulary that E2 deliberately leaves open.

| Term | Definition |
|------|------------|
| **Adapter (integration seam)** | A class that is the only place knowing an external system's endpoint, payload shape, and credential: `AIService` for OpenAI, `GitHubService` for GitHub. Replacing a provider means replacing the adapter behind an unchanged method signature ([ADR-007](A09-architecture-decisions.md#adr-007-application-owned-ai-adapter-over-laravel-http), [§ 5.2.4](A05-building-block-view.md#524-whitebox-integration-adapters)). |
| **Acceptance test (suite)** | Herold's primary automated test level: HTTP-round-trip tests in `tests/Acceptance/` with faked external boundaries ([§ 8.11](A08-cross-cutting-concepts.md#811-development-and-test-concept)). |
| **Base32** | RFC 4648 text encoding used for the TOTP shared secret in `otpauth://` provisioning; encoder/decoder are home-rolled in `AuthController` ([§ 8.4](A08-cross-cutting-concepts.md#84-authentication-and-session)). |
| **C4 model** | Diagram vocabulary (context, container, component) used for the context and building-block diagrams via C4-PlantUML ([chapter 3](A03-context-and-scope.md), [chapter 5](A05-building-block-view.md)). |
| **Deploy-root marker** | The empty file `.herold-deploy-root`, placed once in the FTP target directory; every mirror run verifies its presence before syncing with `--delete` armed ([§ 7.2](A07-deployment-view.md#72-infrastructure-level-2--release-pipeline)). |
| **Docker Compose** | Dev-only orchestration of the two containers `app` (`php:8.5-apache`) and `node` (Vite dev server); not part of any production environment ([ADR-002](A09-architecture-decisions.md#adr-002-devprod-parity----apache--synchronous-processing), [§ 7.1.2](A07-deployment-view.md#712-development--docker-compose)). |
| **Eloquent** | Laravel's ActiveRecord ORM; `VoiceNote` and `User` are Eloquent models over SQLite ([§ 8.1](A08-cross-cutting-concepts.md#81-domain-model-and-persistence)). |
| **`.env`** | Laravel's environment file; in production the manually placed, never-deployed carrier of all credentials and host bindings ([S3.3](../spec/S3-inbetriebnahme.md#s33-persistent-state-surfaces), [§ 8.8](A08-cross-cutting-concepts.md#88-secret-handling)). |
| **FTPS / lftp** | FTP over TLS, driven by the `lftp` client in CI (`mirror --reverse --delete`); the sole deployment channel to the shared host ([§ 7.2](A07-deployment-view.md#72-infrastructure-level-2--release-pipeline)). |
| **Inertia.js** | The bridge that lets Laravel controllers render Vue pages with server-driven props — SPA feel without a browser-facing JSON API ([ADR-001](A09-architecture-decisions.md#adr-001-inertiajs-as-frontend-bridge-no-separate-api-layer-for-the-browser-ui)). |
| **JSON mode** | OpenAI chat-completion setting (`response_format: json_object`) forcing a parseable object; `AIService::chat` relies on it and requires `title` + `body` keys ([§ 5.3.1](A05-building-block-view.md#531-whitebox-aiservice)). |
| **MediaRecorder** | Browser API for in-page audio capture; requires a secure origin (HTTPS), which propagates into the hosting preconditions ([§ 8.9](A08-cross-cutting-concepts.md#89-audio-capture-and-storage)). |
| **Middleware** | Laravel's request-interception chain; Herold uses the stock session `auth` guard, per-route `throttle` limiters, and the custom `SecurityHeaders` ([§ 5.2.2](A05-building-block-view.md#522-whitebox-web-edge)). |
| **Monolog tap** | A configurable hook on a Laravel log channel; `RedactSecrets` uses it to install the secret-masking processor on every channel ([§ 8.7](A08-cross-cutting-concepts.md#87-logging)). |
| **Provisioning URI** | The `otpauth://totp/…` URI encoding issuer, account, and Base32 secret; rendered as a QR code client-side at TOTP enrolment ([§ 6.4](A06-runtime-view.md#64-sign-in-with-inline-totp-enrolment)). |
| **Session guard** | Laravel's cookie-session authentication (`web` guard); the single gate in front of all operator-facing routes ([§ 8.4](A08-cross-cutting-concepts.md#84-authentication-and-session)). |
| **Singleton trigger** | The SQLite `BEFORE INSERT` trigger `enforce_users_singleton` that aborts any second `users` row — the database-level half of the single-operator rule ([§ 8.1](A08-cross-cutting-concepts.md#81-domain-model-and-persistence)). |
| **SQLite** | Embedded, file-based RDBMS; the entire application database is `database/data/database.sqlite` ([ADR-005](A09-architecture-decisions.md#adr-005-sqlite-as-embedded-persistence)). |
| **Throttle** | Laravel rate-limiting middleware, notated `throttle:attempts,minutes` (e.g. `throttle:5,1` on the sign-in factors) ([§ 8.3](A08-cross-cutting-concepts.md#83-validation)). |
| **ULID** | Universally Unique Lexicographically Sortable Identifier — 26-char, time-ordered primary key of `voice_notes`; realises the time-sortable `Identifier` of [D2.2](../spec/D2-datentypen.md#d22-identifier) and names the audio files. |
| **Vite** | Frontend build tool (Rolldown bundler); dev server with HMR in the `node` container, static production build in CI (`public/build/`) ([ADR-006](A09-architecture-decisions.md#adr-006-off-host-frontend-build-with-vite)). |
| **Vuetify** | Material-Design component library for Vue; supplies the responsive UI chrome and theming ([§ 8.10](A08-cross-cutting-concepts.md#810-ui-architecture)). |
| **WAL-safe backup** | Backing up SQLite via its own `.backup` command so the copy is consistent even with a write-ahead log; used by `scripts/backup.sh` ([§ 7.2](A07-deployment-view.md#72-infrastructure-level-2--release-pipeline)). |
